# The design layer migrates from the v1 free-form doc to the framework's multi-context schema

<a id="adr-0013"></a>

The v1 design layer (`docs/hub-design.html` — a hand-authored architecture page — plus a root `CONTEXT.md` glossary and `design_changelog.md` as an informal decision history) predated the design-centered skill framework adopted for this repo and had no machine-checked structure: no anchors, no coverage map, no enforced spine. Migrated to `docs/design/design.md` (root context, the `bb_mcuhub` library) plus `docs/design/segby-v1/design.md` (a second context for the `segby_v1` worked example, split out because the user wanted the separately-deployed example tracked on its own even though most of its vocabulary is inherited from the library), each with its own anchored `CONTEXT.md`, and a `docs/CONTEXT-MAP.md` declaring `segby_v1` as a customer/conformist of `bb_mcuhub`. Every term and decision the v1 documents held is carried forward faithfully — nothing designed was dropped, only re-homed and machine-validated — so the layer gains a render/link-integrity gate (`scripts/design-render`, `scripts/layer-integrity`) without losing any prior intent. `docs/hub-design.html`, the root `CONTEXT.md`, and `design_changelog.md` are retired in this same commit; `git log` on their prior paths remains the record of their history.
